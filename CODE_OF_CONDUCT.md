# Code of conduct

This project is governed by the Contributor Covenant, version 2.1, which is
published at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
and is adopted here as it stands. It is referred to rather than copied so that
what applies is the text at that address and not a copy of it that has drifted.

It covers the issues, the pull requests, the commit messages and anywhere else
a person speaks for this project.

## Reporting

Write to micheltouglo@gmail.com. Reports are read by the maintainer, who is one
person, so say in the first line what happened and where, and expect an
acknowledgement rather than a resolution within a few days.

A report is kept to the people who have to read it to answer it, and the
reporter is not named to the person reported without being asked first.

A conflict of interest is possible here and worth saying out loud: a report
about the maintainer goes to the same address as any other. Where that is not
something you are willing to do, GitHub takes reports about a repository's
maintainer at <https://support.github.com/contact/report-abuse>.

## What this is not

This is not where a vulnerability goes. `SECURITY.md` says where, and why not
into an issue.
