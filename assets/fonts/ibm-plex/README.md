# IBM Plex web fonts

The console and account application ship the Latin-1 WOFF2 subsets of IBM
Plex Sans (Regular, Medium, SemiBold) and IBM Plex Mono (Regular, Medium).

- Upstream: https://github.com/IBM/plex
- Revision: `763c36ef9117782905ae010056dfbe8fd2653a25`
- Retrieved: 2026-09-27
- License: SIL Open Font License 1.1, copied in `LICENSE.txt`
- Modifications: none

The subsets keep the English and French interfaces small. Characters outside
Latin-1 fall back to the platform font named after Plex in each stack.
